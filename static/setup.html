Welcome to IssueMesh

IssueMesh searches and connects engineering issues across GitHub, Jira and Launchpad.

  • Local-only application: Runs entirely on your workstation or private server
  • Read-only tracker access: Never modifies, closes, comments, or deletes tracker objects
  • Local embedded datastore: SQLite database with full-text search and graph relationship memory
GitHub Configuration

IssueMesh uses read-only personal access tokens to query repository issues, discussions, and pull requests.

Requires read-only scopes: repo or public_repo, read:org.
Jira Configuration

Connect to Atlassian Jira Cloud or Server using API tokens.

Launchpad Configuration

Public Launchpad bugs and Ubuntu packages can be searched without credentials.

Model Endpoint (OpenAI-Compatible)

Configure an OpenAI-compatible endpoint for reasoning, graph traversal planning, and evidence synthesis.

Supports OpenAI, local vLLM, Ollama, Azure OpenAI, or any gateway.
Local Memory & Storage

IssueMesh stores previously retrieved tracker objects and their relationships locally to make future searches faster and deeper.

Embedded SQLite database with WAL mode and FTS5 indexing. Local only.
Minimal (~1 MB)

Budget limit for explored related objects (default: 100)
